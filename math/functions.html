Functions: one input, one output

You press B4 on a vending machine and get chips. What if the same button sometimes gave you gum instead? A function is like a dependable machine: put in a number and it always gives back one definite result. We will look at the same function four ways (machine, table, mapping diagram and graph) and then learn to read “how fast things change” straight from a graph.

⚠️ Common mix-up:Two different inputs sharing the same output is fine (2 and −2 both square to 4), and it is still a function. What is NOT allowed is one input with two or more different outputs.

Explore: the function machine

Pick a rule, set the input x and press Feed. Each result is added to the table and plotted as a point. Try the mystery rule: feed it several numbers and figure out what the machine does!

Advanced: build your own y = ax² + bx + c, and spot linear vs quadratic from differences

Explore: build a walking story

Drag the dots to set the distance from home at each time, then press Play to watch the walker. Steeper means faster, flat means stopped, and sloping down means heading back home.

Challenge: make a story where you walk to the park, rest, then run home. Is the rate of change on the way home positive or negative?

👩‍🏫 Teacher notes

Supports Georgia 8.FGR (a function assigns exactly one output to each input; representing functions with tables, mapping diagrams, graphs and equations; linear vs nonlinear functions; describing a functional relationship from a graph and interpreting rate of change). Step 4 deliberately contrasts “one input, two outputs” with “two inputs, one output”, the most common misconception. For the walking graph in step 9, have students tell the story aloud before playing it. The mystery rule in Explore works well in pairs: one feeds numbers, the other guesses.
