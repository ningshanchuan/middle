# 中文朗读稿规则（给 TTS 的 `say` 字段）

`send` 是页面上的显示文字；`say` 是普通话语音合成（MOSS-TTS，女声 Serena）要逐字读出的稿子，听众是中国和美国的中学生。
目标：读出来和一位好老师照着这段文字讲的一模一样——意思、用词、顺序不变，只把"看得懂、读不准"的写法改成"怎么读就怎么写"。

## 总原则
1. **不增不减不改意思。** 不总结、不润色、不换说法、不调整语序（下面列出的个别情况除外）。每个汉字词都要保留。
2. **凡是要读出声的东西，都写成汉字读法**：阿拉伯数字、符号、单位、上标、分数等。`say` 里不应再有阿拉伯数字（英文单词和缩写里的字母除外）。
3. 标点只用中文标点（，。、；：？！“”……）。汉字之间不留空格；英文单词前后可以留一个空格。
4. 拿不准时，按中国中学课堂上老师的读法。

## 数字
- 数值按读法：270 → 二百七十；85,000 → 八万五千；12,700 → 一万二千七百；0.9 → 零点九；34.0 → 三十四点零；1.5×10⁸ → 一点五乘十的八次方
- 量词前的 2 读"两"：2 个 → 两个；2 倍 → 两倍；但 2 号、第 2、2 度、2 米 → 二 / 两（"2 米"读"两米"，"第 2"读"第二"）
- 年份逐字读：1665 年 → 一六六五年；1856–1863 年 → 一八五六年到一八六三年；20 世纪 → 二十世纪；90 年代 → 九十年代
- 日期时间：2026-11-18 → 二〇二六年十一月十八日；20:15 → 二十点十五分；21:00 → 二十一点；10:30 → 十点三十分
- 序号、编号：第 3 层 → 第三层；3 号 → 三号；编号/型号/电话逐位读
- 百分数：百分之0.9 → 百分之零点九；60% → 百分之六十；+百分之18.2 → 增加百分之十八点二（正号表示变化时读"增加"，或读"正"）
- 分数：3分之2 → 三分之二；1/2 → 二分之一；½ → 二分之一；4½ → 四又二分之一
- 比：3:4 → 三比四
- 负数：-34 度（太阳高度、角度）→ 负三十四度；气温 -5℃ → 零下五摄氏度；纬度 -22.5 度 → 南纬二十二点五度；经度负值 → 西经；负4 → 负四
- 范围：3–5 天 → 三到五天；第 3–12 族 → 第三到第十二族
- 约数和近似：约 5000 颗 → 约五千颗；≈ → 约等于

## 单位（顺序不变）
- 20公里/小时 → 二十公里每小时（不要改成"每小时二十公里"）；3 m/s → 三米每秒；9.8 m/s² → 九点八米每二次方秒
- km 千米，m 米，cm 厘米，mm 毫米，kg 千克，g 克，t 吨，s 秒，min 分钟，h 小时，L 升，mL 毫升，N 牛，J 焦，kJ 千焦，W 瓦，kW 千瓦，kWh / kW·h 千瓦时，Pa 帕，V 伏，A 安，Ω 欧，Hz 赫兹，K 开，℃/°C 摄氏度，° 度，g/cm³ 克每立方厘米，kg/m³ 千克每立方米，m² 平方米，cm³ 立方厘米，B 字节，MB 兆字节
- 天文单位、光年、等（星等）照常：6 等 → 六等

## 符号
- 数学：+ 加，− 减，× / 乘 乘，÷ 除以，= 等于，≠ 不等于，> 大于，< 小于，≥ 大于等于，≤ 小于等于，√ 根号，² 的平方，³ 的立方，xⁿ x的n次方，|a| a的绝对值，∠B 角B，△ABC 三角形ABC，∽ 相似于，≌ 全等于，A′ A撇，π 派
- `+` 在词语之间（不是算式）按意思读"和""加上"或用顿号：心脏 + 血管 + 血液 → 心脏、血管和血液；水 + 少量盐 + 糖 → 水加少量盐和糖
- `/` 按意思：A / B（二选一或并列）→ A或B / A、B；单位之间 → 每
- `·`：人名、译名里的保留（罗伯特·胡克）；作分隔符时改成"、"或"，"（细胞核等于市政府 · 线粒体等于发电厂 → 细胞核等于市政府，线粒体等于发电厂）
- 破折号 —— 保留作停顿或改成逗号；省略号 …… 保留
- 括号：去掉括号，内容保留，前后用逗号隔开读顺；括号里只是英文原名或缩写的，保留英文
- 填空的横线 ____ → "空格"（若是在问"是什么"，读"什么"）
- 占位的 ? → "问号"
- 希腊字母：α 阿尔法，β 贝塔，γ 伽马，Δ 德尔塔，θ 西塔，μ 缪，ε 艾普西龙，ρ 柔，λ 兰布达，ω 欧米伽；Δv → 德尔塔v
- 星号：人马座 A* → 人马座A星

## 化学和生物
- 化学式按中国课堂读法：字母照读，下标读汉字数字：H₂O / H2O → H二O；CO₂ → CO二；Fe₂O₃ → Fe二O三；O=O 键 → 氧氧双键
- 离子：Na⁺ → 钠离子；Cl⁻ → 氯离子；H⁺ → 氢离子；OH⁻ → 氢氧根离子；Ca²⁺ → 钙离子。若前面已经有同名的中文（"钠离子（Na⁺）"），只读一次"钠离子"
- DNA、RNA、ATP、mRNA、tRNA、LDL、pH 等缩写保持英文字母原样；碱基配对 A–T → A和T配对 / A对T（按句意），G–C 同理

## 英文、拼音、其他文字
- 英文单词、英文名称照原样保留（语音能读英文）。下划线换成空格：Des_Callaghan → Des Callaghan
- 拼音（带声调符号）紧跟在汉字后面作注音的，删掉拼音，只读汉字（读汉字本身就给出了读音）：三 sān → 三；四合院（sìhéyuàn）→ 四合院
- 俄文等其他文字原样保留

## 图片署名
- "图片：作者 · CC BY-SA 4.0 · 来源" → "图片作者 作者名，知识共享许可。"；Public domain → 公有领域；不读网址、不读"来源"二字以外的链接文字

## 不要改的
- 普通汉字句子原样照抄（包括"立冬。冬季开始。"这种标题加短释义的写法，不要合并改写）
- 已经是读法的不要再改（"等于""乘""除以""的平方""百分之六十"）

## 例子
- 月球的本影很小，落到地球上最多形成一个约 270 千米宽的黑斑。 → 月球的本影很小，落到地球上最多形成一个约二百七十千米宽的黑斑。
- 纬度 34.0 度 ，2026-11-18 20:15：完全的黑夜（太阳高度 -34 度 ）。月球被照亮 百分之65，在南方 50 度 高。 → 纬度三十四点零度，二〇二六年十一月十八日二十点十五分：完全的黑夜，太阳高度负三十四度。月球被照亮百分之六十五，在南方五十度高。
- 罗伯特·胡克 1665 年看到的正是这样。 → 罗伯特·胡克一六六五年看到的正是这样。
- 循环系统 等于 心脏 + 血管 + 血液 → 循环系统等于心脏、血管和血液
- 溶酶体 等于 回收站 / 清洁队 → 溶酶体等于回收站或清洁队
- 汽车以20公里/小时的速度行驶。 → 汽车以二十公里每小时的速度行驶。
- 光在真空中的速度约为 3.0 乘 10⁸ m/s。 → 光在真空中的速度约为三点零乘十的八次方米每秒。
- 1 kWh等于3.6 乘 10⁶ J。 → 一千瓦时等于三点六乘十的六次方焦。
- 钠离子（Na⁺） 和氯离子（Cl⁻） 互相吸引 → 钠离子和氯离子互相吸引
- pH 表示溶液中氢离子（H⁺） 的多少：H⁺ 越多，pH 越小 → pH 表示溶液中氢离子的多少：氢离子越多，pH 越小
- 孟德尔在 1856–1863 年的豌豆实验中发现 → 孟德尔在一八五六年到一八六三年的豌豆实验中发现
- 所以 G–C 对比 A–T 对更牢固一些。 → 所以G和C的配对比A和T的配对更牢固一些。
- 钠钾____消耗 ATP → 钠钾什么消耗 ATP（若这是要学生填的空）
- 绝对值： |a| 就是这个距离，所以 |a| 等于 |负a| 。 → 绝对值：a的绝对值就是这个距离，所以a的绝对值等于负a的绝对值。
- AB等于AC，所以两个底角 ∠B 与 ∠C 相等。 → AB等于AC，所以两个底角角B与角C相等。
- 三 sān · 共3画 → 三，共三画
- 地球绕太阳运行一圈约需 365¼ 天 → 地球绕太阳运行一圈约需三百六十五又四分之一天
- 实验中泡在蒸馏水里的鸡蛋平均变化了 +百分之18.2。 → 实验中泡在蒸馏水里的鸡蛋平均变化了正百分之十八点二。
- 光合作用就在这里进行。图片：Des_Callaghan · CC BY-SA 4.0 · 来源 → 光合作用就在这里进行。图片作者 Des Callaghan，知识共享许可。
- 放大 85,000 倍 → 放大八万五千倍
- 第 3 层最多 18 个电子 → 第三层最多十八个电子
- 2 个分子，每个分子含 1 个氮原子，一共有 2 个。 → 两个分子，每个分子含一个氮原子，一共有两个。
- 水的密度是 1.00 g/ 立方厘米 （室温下约 0.998）。所以 1 mL 水的质量就是 1 g——很好记！ → 水的密度是一点零零克每立方厘米，室温下约零点九九八。所以一毫升水的质量就是一克——很好记！（英文单位和中文单位混写时，英文单位也要换成中文：g → 克）
- 容易混淆：需要 2 个 O2，而不是 1 个：生成物中共有 4 个氧原子（CO2 中 2 个，每个 H2O 中 1 个）。 → 容易混淆：需要两个O二，而不是一个：生成物中共有四个氧原子，CO二中两个，每个H二O中一个。（化学式里的数字一定写成汉字，否则语音会读错，例如把 H2O 读成“H它O”）
- 佐治亚州亚特兰大，2026-11-18 15:00：白天（太阳高度 11 度 ）。 → 佐治亚州亚特兰大，二〇二六年十一月十八日十五点：白天，太阳高度十一度。
- 北纬 53.6 度 ,西经 65.9 度 · 北美洲 · 加拿大 → 北纬五十三点六度，西经六十五点九度，北美洲，加拿大
- UTC减4。这个时区比 UTC 晚 4 小时 → UTC减四。这个时区比 UTC 晚四小时；UTC+4 → UTC加四
- 人口密度：约 389 人/平方千米 → 人口密度：约每平方千米三百八十九人（"人/平方千米"这种按面积计的密度，按中文习惯读“每平方千米……人”）
- 州长 30-15-6：30 岁，入籍 15 年 → 州长三十、十五、六：三十岁，入籍十五年（用短横连起来的几个数，逐个读，中间停顿）
- 海拔约减154米 / 温度减5度 → 海拔约负一百五十四米 / 温度零下五度（"减"紧挨在数字前、前面没有被减数时，是导出时把负号写成了"减"，按负数读）；但"UTC减4"是时区，读"UTC减四"
