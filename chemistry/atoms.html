👩‍🏫 Teacher notes

Supports GSE S8P1 (structure of matter): use models to describe atoms (protons, neutrons, electrons), atomic number, mass number, isotopes and ions. Suggested moves: (1) change ONLY neutrons and ask “did the element change?” (isotopes); (2) change ONLY electrons and discuss charge (ions); (3) change ONLY protons and watch the element name change instantly. Use the gold-foil sim to discuss how evidence changes models. Note: the 2-8-8 shell rule is a simplification that works for elements 1–20.
