How is the table organized?

In 1869 Dmitri Mendeleev arranged the elements by mass and boldly left gaps for elements nobody had discovered yet. Today’s table is ordered by atomic number.

➡️

Periods = rows (7)

Elements in the same period have the same number of electron shells. Moving right, each element has one more proton and one more electron.

⬇️

Groups = columns (18)

Elements in the same group have the same number of outer (valence) electrons, so they react in similar ways, like a family.

🪜

Metals, nonmetals, metalloids

Metals are on the left and in the middle (about 3/4 of all elements), nonmetals are in the upper right, and metalloids sit along the “staircase” between them.

⚠️ Common mix-up:Hydrogen sits in group 1 at the top left, but it is a NONMETAL, not an alkali metal! It sits there because it has just 1 electron.

    👩‍🏫 Teacher notes

    Supports GSE S8P1: organization of the periodic table (periods, groups), location of metals, nonmetals and metalloids, atomic number and atomic mass. Ideas: (1) set Height → Atomic mass and have students describe the trend (increases left→right and top→bottom); (2) set Color → State to find the only two liquid elements (bromine and mercury); (3) compare Bohr models within one group to discover the same number of valence electrons. Data notes: densities are at room conditions (gases are tiny); properties of some superheavy elements are unknown and shown in gray.
